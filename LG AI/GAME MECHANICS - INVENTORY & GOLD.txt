OPEN HOGWARTS - GAME MECHANICS: INVENTORY & GOLD SYSTEM
===========================================================

1. HOW TO OPEN INVENTORY
===========================================================

Hotkey: Press "B" key during gameplay
Source: PlayerHotkeys.cs (line 45)

Code:
  if (InputSystemAgent.GetKeyDown("B")) 
      Menu.Instance.togglePanel("BagPanel");

Result:
  - Opens the BagPanel (UI panel showing inventory slots)
  - Displays 5x5 grid of inventory slots (25 total)
  - Shows current gold at bottom (Galleons/Sickles/Knuts)


2. HOW TO CHECK GOLD AMOUNT
===========================================================

Primary Source: Player.Instance.money
  - Stores total gold as single integer (Knuts)

Displayed In:
  - Inventory Panel: Bottom shows formatted amounts
    * Galleons (10,000 Knuts = 1 Galleon)
    * Sickles (100 Knuts = 1 Sickle)
    * Knuts (base currency)

Display Code:
  Vector3 money = Util.formatMoney(Player.Instance.money);
  // Returns: x=Galleons, y=Sickles, z=Knuts
  
Location in UI:
  Canvas > BagPanel > GalleonLabel / SickleLabel / KnutLabel


3. HOW TO COLLECT GOLD
===========================================================

Method 1: Direct Money Addition
  Player.Instance.money += amount;
  
  This automatically:
  - Updates characterData.money in database
  - Refreshes Inventory UI display
  - Triggers PlayerPanel.updateBar()

Method 2: Via addItem() when buying items
  Player.Instance.addItem(itemId, quantity);
  - Subtracts cost from money via Seller.sellItem()

Method 3: Start game with initial gold
  CreatePanel.cs sets: character.money = 100 (at character creation)

Triggers:
  - Database auto-saves via characterData.save()
  - Inventory panel updates via Inventory.Instance.updateMoney()


4. HOW TO SELL/BUY ITEMS WITH GOLD
===========================================================

BUYING ITEMS:

Step 1: Click on a Seller NPC (Hagrid, shopkeepers, etc.)
  - NPC must have subRace == "Seller"
  - Calls NPC.OnClick() → Seller.OnClick()

Step 2: SellerPanel opens automatically
  - Shows list of available items from database
  - Each item displays: Name, Price (formatted), Icon
  - Button shows Buy button (only active if player has enough gold)

Step 3: Click on desired item
  - SellPanel.selectedItem = tItem (sets selected item)
  - Checks: if (value.price > Player.Instance.money) → disable Buy button

Step 4: Click "Buy" button
  Triggers: SellPanel.buyButton()
  
  Execution:
    1. Check if have enough gold: selectedItem.price <= Player.Instance.money
    2. Play buy sound effect
    3. Deduct gold: Player.Instance.money -= selectedItem.price
    4. Add item: Player.Instance.addItem(selectedItem.id)
    5. Refresh UI: updateMoney()

Source Code: SellPanel.cs (lines 97-106)
  public void buyButton() {
      if (selectedItem == null || selectedItem.price > Player.Instance.money) {
          return;
      }
      sound.Play();
      Player.Instance.money -= selectedItem.price;
      Player.Instance.addItem(selectedItem.id);
      updateMoney();
  }

GOLD CURRENCY SYSTEM
===========================================================

Conversion:
  1 Galleon    = 10,000 Knuts
  1 Sickle     = 100 Knuts
  1 Knut       = 1 Knut (smallest unit)

Example:
  Player has 25,500 Knuts total
  Displays as: 2 Galleons, 55 Sickles, 0 Knuts

Formatting Code: Util.cs
  public static Vector3 formatMoney(int money) {
      int x = money / 10000;              // Galleons
      int y = (money - (x * 10000)) / 100;// Sickles
      int z = (money - (x * 10000) - (y * 100)); // Knuts
      return new Vector3(x, y, z);
  }


DATABASE STORAGE
===========================================================

Character Money:
  Table: "characters"
  Column: "money" (integer, stored as Knuts)
  Persisted: Yes, auto-saves to iBoxDB

Inventory Items:
  Table: "inventory"
  Stores: CharacterItem objects
  Fields:
    - item (item ID)
    - quantity (how many)
    - character (which player owns)
    - slot (inventory grid position)
    - _position (0=bag, 1-6=equipment slots)
