Step 1: Chat with NPC / NPC Shows Mission
=====================================================

Player clicks a Quester NPC (a subclass of NPC with role "Quest").

  [NPC.cs :: OnMouseDown()]
    → checks isInInteractionRange (maxInteractionRange = 5.0f)
    → calls QuestManager.Instance.sendAction(..., Task.ActionType.Talk, ...)
       (this marks any "Talk to NPC" task as progressed)
    → calls OnClick() (virtual, overridden by Quester)

  [Quester.cs :: OnClick()]
    → QuestManager.Instance.getByNPC(Id)  — gets quest IDs assigned to this NPC
    → finds first quest not yet fully rewarded
    → Menu.Instance.showPanel("QuestPanel", false)
    → QuestPanel.setQuest(quest)

  [QuestPanel.cs :: setQuest()]
    → If quest NOT yet accepted:
         title.text = quest.name
         text.text  = quest.pre   ← this IS the NPC's dialogue / mission briefing
         acceptButton shown, completeButton hidden
    → "quest.pre" is a localised string from LanguageManager (key: "QUEST_{id}_PRE")
       defined in DBSetup.setAllQuests()

Evidence — quest pre-text is the NPC's narrative, e.g., Quest 1 asks player to
kill a Castle Spider then talk to NPC id=1. Quest 2 (Hagrid) asks for 8 of item id=26.

=====================================================
Step 3: Process Mission (track progress)
=====================================================

QuestManager.sendAction() is the central dispatcher called whenever the player
does something meaningful. It iterates active quests and matches tasks by type+id.

  [QuestManager.cs :: sendAction(int id, ActorType type, ActionType action, ...)]
    → foreach active Quest → foreach Task
    → if task.type, task.action and task.id match → increment task.currentQuantity
    → if task.quantity reached → task.isCompleted = true
    → calls task.save()   ← updates DB
    → calls task.ui.setStatus(bool) / task.ui.setPhrase() ← updates HUD

Three triggers call sendAction:

  a) Killing an NPC
     [Player.cs line 693]
       QuestManager.Instance.sendAction(id, Task.ActorType.NPC, Task.ActionType.Kill, 1, templateId)

  b) Collecting an item
     [Player.cs line 642]
       QuestManager.Instance.sendAction(id, Task.ActorType.Item, Task.ActionType.GetItem, amount)

  c) Talking to an NPC (clicking on any non-aggressive NPC)
     [NPC.cs line 499]
       QuestManager.Instance.sendAction(data.id, Task.ActorType.NPC, Task.ActionType.Talk, 0, data.template)

Task types available (Task.cs):
  ActionType: Kill=1, Talk=2, GetItem=3, RemoveItem=4, Visit=5
  ActorType:  NPC=1, Place=2, Item=3
  IdType:     Id=1 (specific NPC), Template=2 (any NPC of that template)

HUD update:
  TaskUI.cs :: setStatus(bool) appends ✔ or ✘ to the task text shown in PlayerPanel.

=====================================================
Step 4: Finish Mission (completion check)
=====================================================

  [Quest.cs :: isCompleted (getter)]
    → iterates all tasks in quest.tasks
    → if ANY task.isCompleted == false → returns false
    → once ALL tasks done → sets _isCompleted = true and returns true

This is evaluated lazily — checked whenever QuestPanel.setQuest() is called
(i.e., when the player returns to the Quester NPC).

  [QuestPanel.cs :: setQuest()]
    → if quest.isCompleted AND quest is still in active quests:
         text.text = quest.after   ← NPC's closing dialogue / reward text
         completeButton shown, acceptButton hidden

=====================================================
Step 5: Receive Reward
=====================================================

  [QuestPanel.cs :: OnAcceptReward()]  — triggered by Complete button in UI
    → QuestManager.Instance.completeQuest(quest)
    → text.text = LanguageManager.get("QUEST_ACCEPTED")
    → Plays SoundManager.Effect.QuestComplete audio

  [QuestManager.cs :: completeQuest(Quest quest)]
    → foreach task in quest.tasks → Service.db.Delete("tasks", id)  ← removes from DB
    → foreach entry in quest.loot → Player.Instance.addItem(entry.Key, entry.Value)
         ← gives items to player inventory
    → quests.Remove(quest.id)        ← removes from active quest list
    → Destroy(quest.ui.gameObject)   ← removes from HUD

Reward data is set in DBSetup.setAllQuests() via quest.loot.Add(itemId, quantity).
Example: quest 1 and quest 2 both give 4x item id=3.

=====================================================
Bugs Fixed (2026-06-25)
=====================================================

BUG 1 — Quester.cs crash (IndexOutOfRangeException)
  BEFORE: quests[0] was called on the list returned by getByNPC() without
          checking if the list was empty. If no quests were assigned to the
          NPC the game would crash.
  AFTER:  Guard added — returns early if questIds.Count == 0.
          Also skips quests that are completed AND already removed from active
          quests (fully rewarded), preventing the infinite-reward loop below.

BUG 2 — QuestPanel infinite reward loop
  BEFORE: setQuest() showed the completeButton whenever quest.isCompleted==true,
          including AFTER the quest had already been rewarded and removed from
          active quests. Clicking Complete again would grant loot a second time.
  AFTER:  completeButton is now only shown when quest.isCompleted==true AND the
          quest is still present in QuestManager.quests (active quests). Once
          completeQuest() removes it, re-opening the panel shows nothing.

Files changed:
  Assets/Scripts/NPC/Quester.cs
  Assets/Scripts/UI/Panels/QuestPanel.cs
