=====================================================
OPEN HOGWARTS - FULL OFFLINE MODE FLOW (DETAILED)
=====================================================
Final Goal: Player spawns in Hogwarts, casts a spell, and destroys an NPC.

=====================================================
Phase 1: Game Launch → MainMenu Scene Loads
=====================================================

1. Unity loads the first scene in Build Settings: "MainMenu"

2. GameObject "NetworkManager" (with NetworkManager.cs attached) is ACTIVE in the scene
   → Unity calls NetworkManager.Start():
      - DontDestroyOnLoad(gameObject)         // keeps this object alive across scene loads
      - Instance = this                       // sets static singleton so other scripts can call NetworkManager.Instance
      - Debug.Log("NetworkManager initialized")
      - Registers a lambda callback on SceneManager.sceneLoaded event:
           When ANY scene loads, check if scene.name == "Hogwarts"
           If yes AND useOffline==true AND PhotonNetwork.offlineMode==false → call startConnection()
           (This is a fallback, NOT used in the normal offline flow below)
   
   NOTE: [SerializeField] bool useOffline = true  ← must be CHECKED in Unity Inspector

3. GameObject "Canvas" (with Menu.cs attached) is ACTIVE in the scene
   → Unity calls Menu.Awake():
      - DontDestroyOnLoad(transform.gameObject)   // Canvas persists across scenes
      - DontDestroyOnLoad(GameObject.Find("EventSystem"))  // EventSystem persists too
      - SceneManager.sceneLoaded += OnLevelFinishedLoading // register scene callback
      - _instance = this                          // singleton

4. Menu.OnLevelFinishedLoading(scene="MainMenu", mode) fires:
   → case "MainMenu":
      - showPanel("MainPanel")
        → hideAllPanels() — disables all UI panels
        → getPanel("MainPanel") — finds MainPanel in Menus list
        → MainPanel.SetActive(true)

5. MainPanel.OnEnable() fires (because MainPanel just became active):
   → bool hasPlayer = false
   → Checks: Service.db.SelectCount("FROM item") < 1?
      - If YES (first time, DB empty) → DBSetup.start()
        - DBSetup.insertItems()          // inserts 26 item records
        - DBSetup.insertTestItems()      // inserts a test CharacterItem
        - DBSetup.insertNPCTemplates()   // inserts CastleSpider + Human templates
        - DBSetup.insertNPCs()           // inserts 11 NPCs (Mike Ghole, spiders, Hagrid, students, Draco, etc.)
   → Queries: Service.db.Select<CharacterData>("FROM characters")
      - If character exists:
        - hasPlayer = true
        - Shows nickLabel (character name)
        - Shows LevelLabel (character level)
        - Shows JoinButton (with onClick → joinGame(character.id, character.name))
        - Hides CreateButton
      - If NO character exists:
        - hasPlayer = false
        - Hides nickLabel, LevelLabel, JoinButton
        - Shows CreateButton

=====================================================
Phase 2: Create Character (first time only)
=====================================================

6. User clicks "Create Character" button in MainPanel
   → Menu.Instance.showPanel("CreatePanel") is triggered (via button OnClick in Inspector)
   → CreatePanel becomes active

7. User types a name in the InputField (e.g. "Harry")
   User optionally selects a house from Dropdown (0=Gryffindor, 1=Slytherin, 2=Ravenclaw, 3=Hufflepuff)

8. User clicks "Create" button
   → CreatePanel.createButton() is called:
      
      a) string characterName = nameInput.text.Trim()  // "Harry"
      
      b) Validation:
         - if empty → showError("Please enter a character name.") → return
         - if length < 3 → showError("Name must be at least 3 characters.") → return
      
      c) DB initialization check:
         - if Service.db.SelectCount("FROM item") < 1 → DBSetup.start()
         - (usually already done by MainPanel, so skipped)
      
      d) Create CharacterData object:
         - character.id = 1
         - character.name = "Harry"
         - character.model = "Default"
         - character.level = 1
         - character.house = houseDropdown.value (e.g. 0 for Gryffindor)
         - character.health = 270
         - character.maxHealth = 270
         - character.mana = 100
         - character.maxMana = 100
         - character.exp = 0
         - character.money = 100
         - character.position = "(633.51, 161.38, 415.70)"
      
      e) bool success = character.create()
         → Service.db.Insert("characters", character)
         → Saves to iBoxDB local database
      
      f) If success == false → showError(...) → return
      
      g) Menu.Instance.showPanel("MainPanel")
         → hideAllPanels()
         → MainPanel.SetActive(true)
         → MainPanel.OnEnable() fires again (go to step 9)

=====================================================
Phase 3: Join Game from MainPanel
=====================================================

9. MainPanel.OnEnable() fires:
   → Now finds character "Harry" (id=1) in DB
   → hasPlayer = true
   → nickLabel.text = "Harry"
   → LevelLabel.text = "1"
   → JoinButton is shown with onClick listener: joinGame(1, "Harry")

10. User clicks "Join" button
    → MainPanel.joinGame(characterId=1, name="Harry") is called:
       
       a) if characterId < 1 → return (validation, passes here)
       
       b) Hashtable h = new Hashtable(1)
          h.Add("characterId", 1)
       
       c) PhotonNetwork.player.SetCustomProperties(h)
          → Stores characterId=1 on the local Photon player object
       
       d) PhotonNetwork.player.NickName = "Harry"
          → Sets the player's display name for networking
       
       e) NetworkManager.Instance.startConnection()
          → Calls the method on the singleton we set up in step 2
       
       f) Updates button text:
          GameObject.Find("Canvas/MainPanel/LoginOptions/JoinButton/Text").GetComponent<Text>().text = "Connecting..."

=====================================================
Phase 4: Offline Connection Flow
=====================================================

11. NetworkManager.startConnection() executes:
    → useOffline == true (checked in Inspector)
    → if (PhotonNetwork.offlineMode) return  // false at this point, so continue
    → PhotonNetwork.offlineMode = true
       - Photon SDK enters offline simulation mode
       - No real network connection is made
       - All Photon calls (JoinRoom, Instantiate, etc.) work locally
    → OnJoinedLobby() is called directly (no waiting for server)

12. NetworkManager.OnJoinedLobby() executes:
    → Debug.Log("OnJoinedLobby() called")
    → PhotonNetwork.LoadLevel(Menu.defaultLevel)
       - Menu.defaultLevel = "Hogwarts"
       - Internally calls SceneManager.LoadScene("Hogwarts")
       - MainMenu scene unloads (EXCEPT DontDestroyOnLoad objects: NetworkManager, Canvas, EventSystem)
       - Hogwarts scene begins loading
    → PhotonNetwork.JoinRandomRoom()
       - In offline mode, this immediately creates a local room
       - Triggers OnJoinedRoom() callback

=====================================================
Phase 5: Hogwarts Scene Loads + Player Spawns
=====================================================

13. Hogwarts scene finishes loading
    → All GameObjects in Hogwarts scene are initialized (terrain, NPCs, lighting, etc.)

14. Menu.OnLevelFinishedLoading(scene="Hogwarts", mode) fires:
    → case "default" (not "MainMenu"):
       - showPanel("PlayerPanel")        // shows HP orb, Mana orb, XP bar
       - showPanel("ChatPanel", false)   // shows chat (hidePanels=false, so doesn't hide PlayerPanel)
       - showPanel("TopMenu", false)     // shows top menu bar (Config, Inventory buttons)
       - showPanel("MiniMap", false)     // shows minimap overlay

15. PhotonNetwork triggers OnJoinedRoom() callback on NetworkManager
    (In offline mode this happens almost immediately after JoinRandomRoom)

16. NetworkManager.OnJoinedRoom() executes:
    → Debug.Log("OnJoinedRoom() called - about to spawn player")
    → spawnPlayer()

17. NetworkManager.spawnPlayer() executes:
    → Debug.Log("spawnPlayer() called")
    → Debug.Log("Offline Mode: True")
    
    a) CharacterData character = Service.db.Select<CharacterData>("FROM characters").FirstOrDefault()
       → Retrieves "Harry" (id=1, level=1, 270 HP, 100 mana)
    
    b) if character == null → error + return (not the case here)
    
    c) GameObject player = PhotonNetwork.Instantiate("Characters/Player", new Vector3(633.51f, 161.38f, 415.70f), Quaternion.identity, 0)
       → In offline mode: loads prefab from Resources/Characters/Player
       → Instantiates it at position (633.51, 161.38, 415.70) - the Hogwarts spawn point
       → The prefab contains:
         - Player.cs component (disabled initially)
         - ThirdPersonUserControl (disabled)
         - ThirdPersonCharacter (disabled)
         - PlayerHotkeys (disabled)
         - PlayerCombat (disabled)
         - Rigidbody
         - Animator
         - Child: "Main Camera" (inactive)
         - Child: "NamePlate"
         - Child: "Indicator"
         - Child: "NPCActivator"
         - PhotonView component
    
    d) var playerComponent = player.GetComponent<Player>()
       playerComponent.characterData = character
       → Links the DB character data to the Player component
    
    e) Camera setup:
       var mainCamera = player.transform.Find("Main Camera")
       var cameraController = mainCamera.GetComponent<CameraController>()
       cameraController.cameraTarget = player.transform
       → Camera will follow the player
    
    f) Enable player controls:
       player.GetComponent<ThirdPersonUserControl>().enabled = true   // reads WASD/arrow input
       player.GetComponent<ThirdPersonCharacter>().enabled = true     // handles movement physics + animation
       player.GetComponent<PlayerHotkeys>().enabled = true            // handles key bindings (1,2,3 for spells)
       player.GetComponent<PlayerCombat>().enabled = true             // handles spell casting
    
    g) player.transform.Find("Main Camera").gameObject.SetActive(true)
       → Activates the camera so player can see the world
    
    h) player.transform.Find("NamePlate").gameObject.SetActive(false)
       → Hides own nameplate (you don't see your own name above your head)
    
    i) MiniMap setup:
       GameObject.Find("MiniMapCamera").GetComponent<MiniMap>().target = player.transform
       GameObject.Find("MiniMapElementsCamera").GetComponent<MiniMap>().target = player.transform
       → Minimap follows the player
    
    j) ConfigMenu setup:
       var configMenu = GameObject.Find("Canvas/TopMenu/Config")?.GetComponent<ConfigMenu>()
       if (configMenu != null) configMenu.player = player
    
    k) player.transform.Find("Indicator").GetComponent<Renderer>().material.mainTexture = mmarow
       → Sets the minimap arrow indicator texture

=====================================================
Phase 6: Player Component Initialization
=====================================================

18. Player.Start() fires (on the instantiated player):
    → photonView.isMine == true (we own this player)
    → _instance = this                    // Player.Instance singleton
    → SkillsUI.Instance.displayUnlockedSkills()  // shows available spells in UI
    → startHealthRegeneration()           // starts coroutine to regen HP when out of combat
    → startManaRegeneration()             // starts coroutine to regen Mana when out of combat
    → Destroy(trailRenderer)              // removes trail effect from own player

19. PlayerHotkeys.Awake() fires:
    → Instance = this                     // PlayerHotkeys.Instance singleton

20. PlayerCombat.Start() fires:
    → Instance = this                     // PlayerCombat.Instance singleton
    → spellList.Add(Resources.Load("Spells/Fireball"))    // loads Fireball ScriptableObject
    → spellList.Add(Resources.Load("Spells/Frostbolt"))   // loads Frostbolt ScriptableObject
    → spellList.Add(Resources.Load("Spells/Expecto Patronum"))   // loads AoE spell ScriptableObject
    → SkillsUI.Instance.fillSlots()       // populates the spell bar UI with icons

21. Player.Update() starts running every frame:
    → Updates health bar lerp animation
    → First frame: sends RPC "setNick" to others (no-op in offline)
    → Sets up PlayerPanel bars (HP, Mana, XP)
    → gotFirstUpdate = true

22. ThirdPersonUserControl.Update() runs every frame:
    → Reads WASD/Arrow input
    → Passes movement vector to ThirdPersonCharacter.Move()
    → Player character walks/runs in the Hogwarts world

=====================================================
Phase 7: Player Targets an NPC
=====================================================

23. NPCs in the Hogwarts scene have NPC.cs attached
    → NPC.Start() fires for each NPC:
       - data = NPC.get(Id)              // loads NPCData from DB by Id
       - Sets up nameplate color (red for aggressive, white for friendly)
       - Sets animator or legacy animation
       - initialPos = transform.position
       - maxHealth = health
       - setEnabled(false)               // starts disabled for performance (in builds)

24. NPCActivator on the player enables nearby NPCs:
    → When player walks near an NPC, it calls npc.setEnabled(true)
    → NPC becomes visible and its Update() starts running

25. Player moves camera/mouse over an aggressive NPC (e.g. a CastleSpider or Draco)
    → NPC.OnMouseOver() fires:
       - data.isAggresive == true
       - Cursor changes to GameCursor.Attack (sword icon)

26. Player LEFT-CLICKS on the aggressive NPC
    → NPC.OnMouseDown() fires:
       - setSelected(force=true) is called:
         - PlayerHotkeys.isClickingATarget = true
         - Player.Instance.target = this   // sets the NPC as player's target
           → Player.target setter:
              - _target = npc
              - PlayerPanel.Instance.showTargetPanel(npc.transform)  // shows target frame UI
              - SkillsUI.Instance.updateStatus()  // enables spell buttons (target exists now)

=====================================================
Phase 8: Player Casts a Spell (e.g. Fireball)
=====================================================

27. Player presses key "1" on keyboard
    → PlayerHotkeys.Update() detects:
       - Player.Instance.target != null  (we have a target)
       - InputSystemAgent.GetKeyDown("1") == true
       → PlayerCombat.Instance.spellCast(0) is called

28. PlayerCombat.spellCast(key=0) executes:
    → Player.Instance.target != null  // passes check
    → StartCoroutine(SpellCast(spellList[0], 0))
       - spellList[0] = Fireball (ScriptableObject)

29. PlayerCombat.SpellCast(spell=Fireball, uiPos=0) coroutine starts:
    
    a) Check: spell.spellManaCost > Player.Instance.mana?
       - e.g. Fireball costs 20 mana, player has 100 → passes
       Check: spell.minLevel > Player.Instance.level?
       - e.g. minLevel=0, player level=1 → passes
    
    b) SkillsUI.Instance.disableSkill(0)
       → Greys out the Fireball icon in spell bar (cooldown visual)
    
    c) castingSpell = true
       → Blocks other spell casts and broomstick mount
    
    d) Player.Instance.mana -= spell.spellManaCost
       → Player.mana setter fires:
         - characterData.mana = 80  (100 - 20)
         - characterData.save()     // persists to DB
         - PlayerPanel.Instance.updateBar(BarType.Mana, 80, 100)  // updates UI
         - startManaRegeneration()  // will regen mana when out of combat
    
    e) Player.Instance.anim.SetBool("InvokeSpell", true)
       → Player character starts casting animation (raises wand)
    
    f) PlayerPanel.Instance.castingPanel.Cast("Fireball", spellCastTime)
       → Shows casting bar UI with "Fireball" text + progress bar
    
    g) yield return new WaitForSeconds(spell.spellCastTime - 1.6f)
       → Waits for cast time minus animation time (e.g. 2 - 1.6 = 0.4 seconds)
    
    h) Player.Instance.anim.SetInteger("SpellType", 1)
       Player.Instance.anim.SetBool("InvokeSpell", false)
       → Triggers the spell release animation (wand thrust forward)
    
    i) yield return new WaitForSeconds(1.6f)
       → Waits for the release animation to play (1.6 seconds)
    
    j) SpellSetUp(spell=Fireball) is called

30. PlayerCombat.SpellSetUp(spell=Fireball) executes:
    → spell.spellType == SpellType.Single
    
    Depending on spell.spellDirection:
    
    CASE A: SpellDirection.Directional (projectile flies forward):
       → spellObject = PhotonNetwork.Instantiate("Particles/FireballPrefab", transform.position + transform.up, transform.rotation, 0)
       → Creates a fireball particle at player's position
       → spellObject.name = "Fireball"
    
    CASE B: SpellDirection.Follow (projectile homes on target):
       → spellObject = PhotonNetwork.Instantiate("Particles/FireballPrefab", transform.position + transform.up, Quaternion.identity, 0)
       → spellObject.name = "Fireball"
       → spellObject.GetComponent<SpellObjectConfigurator>().myTarget = Player.Instance.target.transform
         // tells the projectile to follow the NPC
    
    CASE C: SpellDirection.Point (instant at target location):
       → spellObject = PhotonNetwork.Instantiate("Particles/FireballPrefab", target.transform.position, Quaternion.identity, 0)
       → spellObject.name = "Fireball"
       → spellObject.GetComponent<SpellObjectConfigurator>().myTarget = Player.Instance.target.transform

31. After SpellSetUp returns:
    → SkillsUI.Instance.enableSkill(0)    // re-enables Fireball icon in spell bar
    → castingSpell = false                 // allows casting again

=====================================================
Phase 9: Spell Projectile Hits NPC → Damage
=====================================================

32. SpellObjectConfigurator.Start() fires on the instantiated spell object:
    → photonView.isMine == true
    → myTransform = transform
    → spell = Resources.Load("Spells/Fireball")  // loads spell data by object name
    
    IF spell.spellDirection == SpellDirection.Point:
       → Instant damage at target location:
         NPC npc = myTarget.GetComponent<NPC>()
         npc.getHit(Random.Range(spell.spellMinDamage, spell.spellMaxDamage), Player.Instance.gameObject)
         npc.StartCoroutine(npc.TakeDamageByFlagType(spell, Player.Instance.gameObject))

33. SpellObjectConfigurator.Update() runs each frame (for Directional/Follow spells):
    
    IF SpellDirection.Directional:
       → MoveStraightForward():
         myTransform.Translate(new Vector3(0, 0, spell.projectileSpeed * Time.deltaTime))
         // Fireball flies forward each frame
    
    IF SpellDirection.Follow:
       → FollowTarget():
         myTransform.Translate(new Vector3(0, 0, spell.projectileSpeed * Time.deltaTime))
         myTransform.rotation = Quaternion.Slerp(..., LookAt target, 5 * deltaTime)
         // Fireball homes toward the NPC

34. SpellObjectConfigurator.OnCollisionEnter(col) fires when projectile collides with NPC:
    → photonView.isMine == true
    → col.gameObject.tag == "NPC"  // it's an NPC!
    
    a) ContactPoint cp = col.contacts[0]
    
    b) PhotonNetwork.Instantiate("Particles/" + spell.spellCollisionParticle.name, cp.point, Quaternion.identity, 0)
       → Spawns explosion/impact particle effect at hit point
    
    c) NPC npc = col.gameObject.GetComponent<NPC>()
    
    d) int damage = Random.Range(spell.spellMinDamage, spell.spellMaxDamage)
       col.gameObject.GetComponent<NPC>().getHit(damage, Player.Instance.gameObject)
       → Deals damage to the NPC (see step 35)
    
    e) Handle spell flags (DoT, Slow, etc.):
       npc.StartCoroutine(npc.TakeDamageByFlagType(spell, Player.Instance.gameObject))
    
    f) PhotonNetwork.Destroy(this.gameObject)
       → Destroys the fireball projectile

=====================================================
Phase 10: NPC Takes Damage
=====================================================

35. NPC.getHit(damage, attacker=playerGameObject) executes:
    → health -= damage
       - e.g. Spider has 100 HP, takes 45 damage → health = 55
    
    → Player player = attacker.GetComponent<Player>()
    → if (!attackers.ContainsKey(player)) attackers.Add(player, 0)
    → attackers[player] += damage
       // tracks total damage dealt by this player (for XP calculation)
    
    → if (!target) target = attacker
       // NPC now targets the player (will fight back!)
    
    → if (player.isMine) namePlate.setDamage(damage, false)
       // shows floating damage number "-45" above NPC's head

36. NPC.Update() runs next frame:
    → isDead == false (health > 0)
    → target != null (the player)
    → EnableCombat = true
    → NPC chases the player and attacks back:
       - Rotates toward player
       - Moves toward player (data.runSpeed)
       - When in attackRange: plays attack animation + sends getDamage RPC to player
       - Player.getDamage() → player loses HP

=====================================================
Phase 11: NPC Dies (health reaches 0)
=====================================================

37. Player casts more spells (repeats steps 27-35)
    → NPC.health eventually reaches 0

38. NPC.Update() detects isDead == true:
    → killNotiSent == false && photonView.isMine:
    
    a) namePlate.health.fillAmount = 0    // empty health bar
    
    b) For each player in attackers dictionary:
       entry.Key.photonView.RPC("addKill", owner, data.id, ActorType.NPC, data.level, entry.Value, data.health, data.expValue, data.template)
       → In offline mode, calls Player.addKill() directly
    
    c) this.changeAnimation(AnimationStates.DEATH)
       → NPC plays death animation (falls to ground)
    
    d) NPCManager.Instance.prepareRespawn(this)
       → Schedules NPC to respawn after a timer
    
    e) killNotiSent = true
       → NPC.Update() stops processing (isDead returns early)

39. Player.addKill(id, type=NPC, npcLevel, damage, totalHealth, expValue, templateId) executes:
    → Calculates XP:
       - levelDiff = npcLevel - playerLevel
       - if levelDiff > -2: (not too low level)
         - if damage >= totalHealth → full XP (solo kill)
         - else → half XP (assisted)
       - exp += wonExp + (levelDiff * 10)
    
    → Player.exp setter:
       - characterData.exp += wonExp
       - if exp >= XP_BASE * level (400 * 1 = 400) → LEVEL UP!
         - characterData.level += 1
       - characterData.save()
       - PlayerPanel.Instance.showWonXP(value)    // "+120 XP" floating text
       - PlayerPanel.Instance.updateBar(BarType.Exp, ...)  // XP bar fills
    
    → QuestManager.Instance.sendAction(id, ActorType.NPC, ActionType.Kill, 1, templateId)
       → Updates quest progress (e.g. "Kill 1 Castle Spider: 1/1 ✓")

=====================================================
COMPLETE FLOW SUMMARY (OFFLINE MODE)
=====================================================

MainMenu Scene:
  NetworkManager.Start() → Instance = this, DontDestroyOnLoad
  Menu.Awake() → DontDestroyOnLoad, registers callbacks
  Menu.OnLevelFinishedLoading("MainMenu") → showPanel("MainPanel")
  MainPanel.OnEnable() → checks DB, shows Join/Create button
  
  [If no character] User clicks Create → CreatePanel:
    createButton() → validates name → creates CharacterData → saves to DB
    → Menu.Instance.showPanel("MainPanel")
  
  MainPanel.OnEnable() → finds character → shows JoinButton
  
  User clicks Join → MainPanel.joinGame():
    → Sets Photon properties
    → NetworkManager.Instance.startConnection()

Connection:
  startConnection() → useOffline=true
    → PhotonNetwork.offlineMode = true
    → OnJoinedLobby()
      → PhotonNetwork.LoadLevel("Hogwarts")
      → PhotonNetwork.JoinRandomRoom()

Scene Transition:
  Hogwarts scene loads
  Menu.OnLevelFinishedLoading("Hogwarts") → shows PlayerPanel, Chat, TopMenu, MiniMap
  OnJoinedRoom() → spawnPlayer()

Player Spawn:
  spawnPlayer()
    → Reads CharacterData from DB
    → PhotonNetwork.Instantiate("Characters/Player")
    → Configures camera, controls, minimap
    → Player.Start() → initializes singleton, regen, skills
    → PlayerCombat.Start() → loads 3 spells, fills UI

Gameplay:
  Player moves with WASD → ThirdPersonUserControl + ThirdPersonCharacter
  Player clicks NPC → NPC.OnMouseDown() → Player.target = npc
  Player presses "1" → PlayerHotkeys → PlayerCombat.spellCast(0)
  SpellCast coroutine → casting animation → SpellSetUp → instantiates projectile
  Projectile flies/homes → OnCollisionEnter → NPC.getHit(damage)
  NPC health reaches 0 → death animation → Player gets XP → quest progress updates

=====================================================
KEY OBJECTS REQUIRED IN MAINMENU SCENE (Inspector)
=====================================================

1. GameObject "NetworkManager"
   - Script: NetworkManager.cs
   - useOffline: ✓ (checked)
   - mmarow: assign minimap arrow texture

2. GameObject "Canvas"
   - Script: Menu.cs
   - Menus list: [MainPanel, CreatePanel, PlayerPanel, ChatPanel, TopMenu, MiniMap, ConfigPanel, BagPanel, CharacterPanel, GameOverPanel, etc.]
   - Contains all UI panels as children

3. GameObject "Canvas/MainPanel"
   - Script: MainPanel.cs
   - nickLabel, LevelLabel, JoinButton assigned in Inspector

4. GameObject "Canvas/CreatePanel"
   - Script: CreatePanel.cs
   - nameInput: InputField reference
   - houseDropdown: Dropdown reference (optional)
   - errorText: Text reference (optional)

5. GameObject "EventSystem"
   - Standard Unity EventSystem for UI interaction
